# Skelemarket

**Skelemarket** is a simple supermarket simulation written in Java for school. It includes keeping track of expiry dates, restocking and path finding of customers.

## Features

- **Path Finding** – Different customers follow different paths based on an algorithm
- **Expiry Dates** – Products that have been on the shelves too long will expire
- **Restocking** – Warehouse employees that restock the shelves

## Getting Started

### Prerequisites

Ensure you have the following installed on your system:
- Runtime: [Java JDK 21](./doc/Java-21-help.md)
